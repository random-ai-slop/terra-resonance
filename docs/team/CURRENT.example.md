# Local coordination example

Copy this file to the ignored `docs/team/CURRENT.md` for a coordinated local project. Do not commit account identifiers, task handles or machine paths. Independent contributors need no standing coordinator service.

- Objective and acceptance: describe the user's concrete requested outcome.
- Coordinator and primary path: record locally and supply in dispatches.
- Accepted source: name the actual Git revision and relevant contracts.
- Assignment: task/attempt, owner, exact write paths, dependencies and concurrency allowance.
- Evidence: commands actually run, artifacts inspected and remaining limitations.
- Handoff: completed commits, next consumer and acknowledged accepted input.

Use one current record. Keep durable scientific decisions in maintained documentation. A role charter allows inspection only; a bounded assignment authorizes implementation. Read [WORKFLOW](WORKFLOW.md) for integration and review rules.
